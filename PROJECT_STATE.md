## What this project is

The Small Operator is an independent publication about the real cost and practical tradeoffs of software and services used by small operators and small businesses.

Its editorial model emphasizes evidence quality: distinguish vendor-documented claims from hands-on observations, leave unresolved questions visible, avoid fake testing or invented certainty, and include the real switching/migration cost when evaluating tools.

The repository currently contains the publication site and researched articles, including work on email-marketing alternatives and small-website hosting costs.
